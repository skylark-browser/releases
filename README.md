# Skylark Releases

Skylark is an agentic, Chromium-fork, cross-platform desktop web browser written in Rust.

This repository is the home for Skylark releases. It will be used for releases, release notes, downloadable build references, version metadata, and other release-specific materials as the project takes shape.

This repository is early and intentionally light on details while the release process is being established. More information about supported platforms, release channels, verification, installation, and update guidance will be added as it becomes available.
